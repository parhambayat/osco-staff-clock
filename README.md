# Osco Lounge — Staff Clock

## الان چطور استفاده کنی (همین کامپیوتر کافه)

1. سرور را روشن نگه دار (`npm run dev` در پوشه `osco-lounge`).
2. روی گوشی پرسنل (همان Wi‑Fi کافه) این آدرس را باز کن:
   - `http://IP-COMPUTER:3000`  
   - IP کامپیوتر را از Network settings ببین، یا از من پایین این فایل.
3. برای نصب مثل اپ: در مرورگر گوشی → **Add to Home Screen**.

### پرسنل
- اسم + شماره → کد برای منیجر می‌رود
- منیجر کد را وارد می‌کند روی گوشی پرسنل → ثبت‌نام یک‌بار برای همیشه

### منیجر
- آدرس: `/manager`
- یوزر: `manager`
- پسورد: `in yek ramze`
- لیست پرسنل، ساعات، ویرایش ورود/خروج
- تنظیم واتساپ (یک‌بار) داخل پنل

### واتساپ (یک‌بار)
داخل پنل منیجر دستورالعمل CallMeBot هست. بعد از زدن API key، کدها مستقیم به `+96898983134` می‌آیند.
تا قبل از آن، کدها در بخش **Pending** پنل منیجر دیده می‌شوند.

### ورود/خروج فقط روی Wi‑Fi کافه (مودم Omantel)
پرسنل باید از **لینک آنلاین** (`https://osco-staff-clock.vercel.app`) استفاده کنند، نه IP لوکال کامپیوتر.

IP عمومی مودم Omantel **دینامیک** است و ممکن است عوض شود. اگر روی وای‌فای کافه باز هم پیام *Not connected to Osco Lounge Wi-Fi* آمد:

1. با گوشی روی **همان Wi‑Fi کافه** برو به `/manager`
2. بخش **Café Wi-Fi IP** را باز کن
3. دکمه **Use my current IP** را بزن (بدون redeploy)

یک‌بار در Supabase → SQL Editor فایل `supabase-app-settings.sql` را Run کن تا ذخیره IP در دیتابیس کار کند.

پیش‌فرض‌های build (تا وقتی از پنل ذخیره نکرده‌ای):
- `CAFE_WIFI_IP` = `37.40.224.218,37.40.226.51,37.40.228.63` (چند IP با کاما مجاز است)
- `LOCAL_DEV` = `false`

برای تست روی همین PC کافه `LOCAL_DEV=true` بگذار (چک IP خاموش می‌شود).
