# Osco Lounge — Staff Clock

## الان چطور استفاده کنی (همین کامپیوتر کافه)

1. سرور را روشن نگه دار (`npm run dev` در پوشه `osco-lounge`).
2. روی گوشی پرسنل (همان Wi‑Fi کافه) این آدرس را باز کن:
   - `http://IP-COMPUTER:3000`  
   - IP کامپیوتر را از Network settings ببین، یا از من پایین این فایل.
3. برای نصب مثل اپ: در مرورگر گوشی → **Add to Home Screen**.

### پرسنل
- اسم + شماره → کد برای منیجر می‌رود
- منیجر کد را وارد می‌کند روی گوشی پرسنل → ثبت‌نام یک‌بار برای همیشه

### منیجر
- آدرس: `/manager`
- یوزر: `manager`
- پسورد: `in yek ramze`
- لیست پرسنل، ساعات، ویرایش ورود/خروج
- تنظیم واتساپ (یک‌بار) داخل پنل

### واتساپ (یک‌بار)
داخل پنل منیجر دستورالعمل CallMeBot هست. بعد از زدن API key، کدها مستقیم به `+96898983134` می‌آیند.
تا قبل از آن، کدها در بخش **Pending** پنل منیجر دیده می‌شوند.

### ورود/خروج در کافه (موقعیت مکانی — پایدار)
IP عمومی مودم Omantel (BROVI 5G) **دائم عوض می‌شود**؛ عدد `192.168.8.1` روی برچسب مودم فقط آدرس داخلی شبکه است و برای اینترنت/سرور قابل استفاده نیست.

راه‌حل پایدار:
1. با گوشی در خود کافه برو به `/manager`
2. **Set café location here** را بزن (دسترسی Location را Allow کن)
3. بعد از آن پرسنل با GPS نزدیک کافه ورود/خروج می‌زنند — عوض شدن IP دیگر مهم نیست

تا وقتی لوکیشن ست نشده، چک موقت Wi‑Fi IP هنوز هست (شکننده است).

- `LOCAL_DEV=true` روی PC تست، چک حضور را هم برای توسعه محلی راحت‌تر می‌کند (IP skip)

برای تست روی همین PC کافه `LOCAL_DEV=true` بگذار.
