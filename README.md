# Osco Lounge — Staff Clock

## Production
لینک آنلاین: `https://osco-staff-clock.vercel.app`

### پرسنل
- اسم + شماره → کد برای منیجر می‌رود
- منیجر کد را وارد می‌کند روی گوشی پرسنل → ثبت‌نام یک‌بار برای همیشه
- ورود/خروج فقط **داخل کافه** (GPS)

### منیجر
- آدرس: `/manager`
- یوزر: `manager`
- پسورد: `in yek ramze`
- لیست پرسنل، ساعات، ویرایش ورود/خروج
- **Set café location here** را یک‌بار در خود کافه بزن (Allow Location)

### ورود/خروج (موقعیت مکانی)
پرسنل فقط وقتی نزدیک Osco Lounge باشند می‌توانند punch کنند.
لوکیشن کافه را منیجر از پنل ست می‌کند.

اگر GPS یک گوشی خراب است:
1. منیجر → همان پرسنل → **Create device pass code**
2. کد ۶ رقمی را روی همان گوشی خراب یک‌بار وارد کن (Broken GPS? Enter device pass)
3. فقط همان گوشی بدون لوکیشن می‌تواند punch کند (حداکثر ۵ گوشی)

### واتساپ (اختیاری)
داخل پنل منیجر دستورالعمل CallMeBot هست. تا قبل از آن، کدها در **Pending** دیده می‌شوند.

### توسعه محلی
`LOCAL_DEV=true` چک GPS را برای تست روی PC خاموش می‌کند.
جداول: `supabase-schema.sql`
