# Osco Lounge — Staff Clock

## Production
لینک آنلاین: `https://osco-staff-clock.vercel.app`

### پرسنل
- **ثبت‌نام جدید** فقط یک‌بار: اسم + شماره → کد منیجر
- برای استفاده روزانه: منیجر برای هر نفر **Personal clock QR** چاپ می‌کند → اسکن = مستقیم چک‌این (بدون شماره)
- ورود/خروج نزدیک کافه (حدود ۸۰۰ متر؛ GPS داخل ساختمان خطای زیاد دارد)

### منیجر
- آدرس: `/manager`
- یوزر: `manager`
- پسورد: `in yek ramze`
- برای هر پرسنل: QR شخصی را چاپ کن و به همان نفر بده
- **Set café location here** را یک‌بار در خود کافه بزن
- اگر GPS یک پرسنل کار نمی‌کند: **Allow punch without location**

### ورود/خروج (موقعیت مکانی)
پرسنل فقط وقتی نزدیک Osco Lounge باشند می‌توانند punch کنند.
لوکیشن کافه را منیجر از پنل ست می‌کند.

اگر GPS یک پرسنل کار نمی‌کند (مثل Sana):
1. منیجر → همان پرسنل → **Allow punch without location**
2. تمام — دیگر نیازی به کد نیست؛ همان پرسنل بدون لوکیشن چک‌این/چک‌اوت می‌کند
3. هر وقت خواستی **Require location again** را بزن

### واتساپ (اختیاری)
داخل پنل منیجر دستورالعمل CallMeBot هست. تا قبل از آن، کدها در **Pending** دیده می‌شوند.

### توسعه محلی
`LOCAL_DEV=true` چک GPS را برای تست روی PC خاموش می‌کند.
جداول: `supabase-schema.sql`
